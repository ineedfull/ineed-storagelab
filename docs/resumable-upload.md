# 上传断点续传

2026-10-28新增，Electron原生功能；普通上传默认行为保持。上传前勾选“启用上传断点续传”，选择8MiB–64GiB普通文件；较小文件使用普通上传。每片8MiB串行发送，内存有界，文件完整SHA-256核验需要额外磁盘读取时间。

## 恢复与放弃

取消或退出保留已确认的远端分片和私有记录。任务中心选择“重新选择文件并续传”，通过原生文件选择器重新授权一个文件；允许文件移动到其他路径，但内容SHA-256和大小必须完全一致。需要当前有效凭证与原连接配置。服务逐页读取ListParts，对号码、大小、ETag严格比较，只跳过已确认且完全匹配的分片。分页接受整数或十进制数字字符串游标，范围1–10000且必须严格递增；拒绝没有分片的截断页，最多8192页/8192片，每页前后检查取消信号。异常分页以 `PARTS_MISMATCH` 结束本次恢复并保留私有检查点，不占用连接无限重试，也不自动清理远端分片。重新恢复生成新任务，旧任务不再提供恢复入口；历史超过200条后仍可从私有记录恢复。

“放弃续传并清理分片”需要原生确认，正常情况下Abort后删除本机记录；清理失败保留记录可再试。连接已变化或删除时不向新地址发请求，只能明确放弃本机记录，并提示到原服务人工检查。最多100个保留记录，防止无限积累。只读连接不能写入或清理远端。

## 安全与兼容

独立应用userData/upload-checkpoints内版本1JSON，只保存目标、连接配置哈希、文件SHA-256/大小、私有UploadId/token、分片和阶段；不保存文件路径或凭证。POSIX目录0700、文件0600及原子写入，读取拒绝不安全或损坏记录；Windows使用系统账户数据目录ACL，Unix mode不是Windows ACL证明。公开IPC只接收任务ID，导出任务不含UploadId/token/文件路径。已有schema1数据库与旧任务兼容。

## 不确定结果

Create、UploadPart和Complete不自动重试。Create响应丢失且没有UploadId时，禁止重新创建，无法自动定位孤儿分片；只能明确放弃本机记录并人工检查原服务。UploadPart响应丢失可能造成远端多出分片，恢复会拒绝不匹配状态，需明确清理后重新上传。

Complete前记录completing，正文Metadata保存私有唯一token；响应不明时用HEAD token和大小核实。能确认则成功，不能确认保留不确定记录；后续恢复仅再次核实，不重复Complete或盲目覆盖。对象随后被其他客户端覆盖时也可能无法确认。此token不是密码，不替代服务权限。

覆盖授权沿用提供商能力规则，不承诺所有S3兼容实现都支持条件写入。文件完成后服务没有额外独立下载校验；本轮测试用独立GET的SHA-256核对正文。下载仍不支持断点恢复。真实云厂商、Windows/Linux原生和人工系统文件选择器验收须单列。
