# StorageLab 工作台

Vue 工作台只通过固定 runtime bridge 调用 Electron preload / IPC。浏览器预览显示明确提示并禁用原生连接、传输和官网操作；测试 fixture 只存在 tests/，不进入生产入口。renderer 不获得长期凭证、磁盘文件路径或任意文件访问接口。原生文件与目录选择由系统 dialog 完成。

左侧按连接分组，列桶失败仍可手输已知桶。对象浏览按原始 Prefix / Key 和不透明 cursor 分页，每页最多200；筛选与排序只作用于当前页。Key 不进行本地路径归一化。完整 Key 在详情查看和复制。属性与预览丢弃已切换对象的旧响应；ETag 只展示。窄窗口详情采用浮动面板，收起后完整浏览表格；任务中心独立页签。

连接编辑凭证留空会保留已有凭证；更换时必须完整填写。系统安全后端不可用时明确选择仅本会话，退出后需重新输入。设置采用草稿预览，取消和保存失败还原；设置/关于不卸载对象浏览与任务。主题、大字、侧栏、并发与超时由原生持久化。语义字号与系列主题 token 集中维护，时间统一走 domain/datetime.js，显示本地毫秒完整时间。

上传和下载默认不覆盖，显式勾选才允许覆盖。任务保留真实进度、状态、速率和错误；重试仅限本会话仍有效文件授权；连接成功保存或移除后撤销其旧任务授权，需重新选择文件/目录并捕获当前连接。删除由原生再次确认，显示逐对象失败及版本状态，不能视为永久删除。分享链接只保留于当前弹窗，不持久化。HTML/SVG 不预览；文本/JSON2MiB、位图8MiB。上传文件按保守后缀设置 Content-Type（txt/log/csv/json/png/jpg/jpeg/gif/webp），未知类型 octet-stream；这是文件名推断元数据，不是内容验证。

## 系列外壳（2026-10-28）

对照 LinkLab 与 NetTool 的既有外壳维护：侧栏展开240px、折叠58px，48px品牌/上下文栏，品牌图标28px（折叠24px）；品牌/上下文14/15px、弹窗标题15/16px、关于产品名20/21px。折叠按钮在品牌栏，提供准确展开/折叠名称、title与aria-expanded；新建和连接始终显示图标。连接/桶区独立滚动，底部设置/关于固定可访问，展开横排图标文字、折叠竖排图标。

设置使用700px上限的系列弹窗，分显示/传输两组；左侧标签说明、右侧控件对齐。主题/大字为草稿预览，取消/关闭/保存失败恢复已存设置，保存中锁定操作。关于使用480px上限和64px标准图标，展示实际版本、运行时、SQLite和独立目录、固定官网入口及Electron内存说明。StorageLab独立站尚未配置，官网继续使用既有原生白名单 `https://www.ineedfull.com`。

所有应用弹窗通过 `AppDialog` 组成系列外壳：48px标题、独立滚动正文、至少56px固定底部操作区。Escape/关闭返回发起按钮焦点；工作台不卸载，对象筛选草稿、选中与传输任务保留。图标引用保持运行时相对URL，兼容Vite和Electron的file入口，不让Vue将public图标解析为组件同目录模块。

## 全窗口布局与操作位置（2026-10-28）

主窗口左侧保留连接资源及固定底部设置/关于，资源标题右侧提供“新建连接”加号。顶部48px上下文栏左侧显示当前连接，右侧依次编辑、检查、移除；命令配lucide图标，移除使用危险语义色。第二行提供对象浏览/任务中心下划线页签及详情开关：沿用LinkLab的轻量导航，移除分段外框与整块选中底色，以强调文字和2px底线标识当前页，任务数量单独显示为小徽标。页签普通40px、大字44px高，当前按钮通过aria-current标识，保留键盘焦点；任务方向继续使用分段筛选，区分页面导航与数据筛选。桶路径、对象操作、筛选和传输选项在各自工作区。任务页的导出/刷新位于标题右侧。切换页签不卸载后台传输或浏览草稿。

| 窗口                   | 宽度上限 | 固定底部操作（从左到右，整体靠右）                   |
| ---------------------- | -------- | ---------------------------------------------------- |
| 新建/编辑连接          | 700px    | 取消、保存连接                                       |
| 设置                   | 700px    | 取消、保存设置                                       |
| 关于                   | 480px    | 关闭                                                 |
| 移除连接               | 480px    | 取消、确认移除连接                                   |
| 分享对象               | 700px    | 关闭、复制链接（生成后）、生成链接                   |
| 复制/重命名/编辑元数据 | 700px    | 取消（完成后为关闭）、确认复制/确认重命名/保存元数据 |
| 对象版本与恢复         | 980px    | 关闭、下载所选版本、恢复为当前对象                   |

所有弹窗使用相同标题/关闭按钮、正文留白、底部分隔线及8px按钮间距；版本表格内分页保留在表格旁，写入命令固定在底栏。固定提交按钮通过form属性关联表单，保留Enter提交和表单校验。忙碌写入阶段禁用关闭与重复提交；焦点循环跳过fieldset内禁用控件并包括可聚焦表格，全部控件禁用时Tab保持在弹窗本身。普通读取/分享生成可以关闭，关闭后迟到的结果或错误不得进入下一次弹窗。

移除连接开始时撤销旧读取响应的有效性，保留当前连接、桶/路径及已显示对象；原生拒绝时继续显示原工作位置，成功后才清理已删除连接上下文。若等待期间已切换连接，完成时不清空其他连接。

`tests/ui/window-consistency.spec.js`覆盖10种窗口×16显示组合、滚动前后底栏、焦点返回、移除失败和分享迟到响应。`tests/native/window-consistency.spec.js`使用真实Electron生产renderer/preload、隔离IPC外观fixture检查窄窗两种主题下全部窗口，不能作为存储服务验收；原生生产启动/安全存储及设置持久化仍由startup/shell-consistency测试独立检查。

## 连接表单（2026-10-28）

新建与编辑共用700px上限的连接弹窗，正文按“连接信息 → 服务配置 → 访问凭证 → 其他选项”组织；名称/分组、区域/默认桶、Access Key/Secret Key成对对齐，完整地址与说明占整行。控件沿用系列高度、8px字段内间距、16px字段间距，分区24px；640px以下单列。提示通过 `aria-describedby` 关联，标签保持独立可读，不把示例当作已填值。

分组仅用于本地侧栏归类；Endpoint填S3 API地址，签名区域按服务端配置填写，Spaces机房地域与签名区域分别说明。提供商助手仍需显式点击才改写地址/区域/寻址方式，切换提供商不改写已有字段。通用S3可手动连接兼容服务，已列厂商优先选对应项以应用厂商能力限制；配置预设不代表账号连通或兼容验收。

普通标签与带帮助按钮的标签行统一最小高度32px，标签文字垂直居中，确保区域与默认桶等并排输入框对齐。新建连接的区域初始留空，切换提供商仍保留当前输入；显式应用提供商配置才填入区域。编辑保留已保存的区域，提交前仍需填写有效区域。

Session Token明确标为临时凭证可选，普通AK/SK留空；编辑不读取已有密钥，全部留空保留，局部更换仍要求完整凭证。公开Base URL是生成公开链接所用的桶访问根地址，与Endpoint独立。保存时锁定表单与关闭操作，拒绝重复提交；错误固定在按钮区，可阅读后继续编辑且保留草稿。正文滚动留出16px焦点空间，固定分隔线与底部操作区不挤占字段。

回归入口：`tests/ui/connection-form.spec.js`验证固定操作区/Enter提交、凭证保留与完整替换、保存锁定与失败草稿；`tests/ui/providers.spec.js`覆盖16显示组合并检查滚动前后操作区位置；`tests/native/shell-consistency.spec.js`覆盖实际Electron隔离宿主三档窗口和两种主题下的表单、焦点及关闭。测试不使用真实账号、不改真实连接。

验证入口：`tests/ui/shell-consistency.spec.js`（16显示组合及折叠/上下文/图片加载）、`tests/native/shell-consistency.spec.js`（实际生产主进程、隔离SQLite、三档窗口、设置重载和关于图片）。浏览器fixture不代表存储服务，原生用本机macOS arm64；本轮不重打安装包。

## 开发与验证

对象浏览工作台按“连接上下文与命令 → 页面切换 → 桶与原始路径 → 对象命令与当前页筛选 → 传输选项 → 列表”组织。目录指示使用lucide ChevronRight（普通18px、大字20px），首列居中，箭头与目录名均能进入原始前缀；当前页筛选同时作用于目录和对象，无匹配时明确提示。选中对象自动展开详情，窄窗浮动详情保留面板内关闭按钮。

按钮组和详情表单引用控件间距8px、分区间距16px的语义变量。分享弹窗正文使用16px纵向间距，生成/复制按钮固定于底栏，与结果文本框保持区域分隔；详情标题/关闭按钮随面板滚动保持可见。

属性面板宽340px，窄窗口浮层上限380px并保留两侧留白。完整原始Key使用6行等宽文本框、代码字号13/16px、1.6行高与12px内边距，自动折行且可向下拖高；显示和复制保留原始空白、斜杠及换行。大小统一由 `domain/file-size.js` 格式化，按1024进位显示B/KB/MB/GB/TB/PB，最多两位小数；属性同时显示精确字节数，列表/版本和任务进度悬停可查原值。零值显示0 B，缺失或无效值显示--；排序、进度计算和底层数据仍使用原始字节数。

对象与版本表格的大小列统一128px，数值靠右、容量及单位单行完整显示。静态长说明统一用 `HelpHint` 的CircleHelp图标，接入对象标签规则、安全预览、任务中心传输说明、Metadata填写规则、版本查询/恢复、分享及连接表单的较长说明。悬停或聚焦显示，移入弹层可继续阅读；点击固定，再次点击、外部点击或Escape收起。弹层使用Chromium原生Popover顶层，在滚动容器与弹窗内不裁剪，并按视口定位；Escape优先关闭帮助。字段保留label/for及aria-describedby关联。只读/能力不支持、失败、凭证保存不可用、整组替换/覆盖提示继续直接显示。`tests/ui/help-hint.spec.js`覆盖鼠标/键盘和16显示组合，原生window-consistency覆盖实际Electron内说明与弹窗Escape分层。

任务卡片使用紧凑三栏：左侧文件名/方向、连接与原始Key，中间容量/百分比/进度，右侧状态和带标签的更新时间。完成的普通任务宽窗约85px高，不保留空操作区，也不展示停止后的0 B/s。只有传输中显示速度；未知总大小时使用不定进度并标明未知，空文件成功显示100%。错误、警告和续传说明保持可见，需要的操作在卡片下方靠右。任务容器小于等于720px时进度单独占行，长Key和连接摘要单行省略并提供完整title，不修改原始数据。`tests/ui/task-cards.spec.js`覆盖完成/传输/未知总大小/空文件/失败及16显示组合，续传、取消和重试沿用既有流程。

任务标题下提供“全部 / 上传 / 下载”方向筛选和各自数量，只作用于当前保留的记录；刷新与切换页面保留筛选，列表滚动时标题与筛选保持可见。导出仍包含全部保留记录，按钮提示和问号帮助明确说明；没有任务时禁用导出。真正无任务显示传输图标、说明和“前往对象浏览”入口；筛选无结果显示对应方向，并提供“查看全部任务”，切回后焦点返回全部按钮。空状态沿用主题变量、居中留白与可换行操作区，支持窄窗和大字。`tests/ui/task-filter.spec.js`覆盖筛选、数量刷新、切页保留、两种空状态、键盘焦点和16显示组合；`tests/native/task-filter.spec.js`验证真实Electron隔离空任务及IPC显示fixture筛选，不代替云存储传输验收。

操作反馈沿用系列的可关闭消息和阅读暂停行为：一般成功6秒收起，悬停、键盘焦点或页面隐藏时暂停；错误、部分失败和需要人工清理的续传警告保留到用户关闭。消息浮层不改变工作区布局，长消息有界滚动，不抢焦点。同目录同页刷新保留行并禁用旧行相关操作；切换桶/路径/分页立即清空旧行，成功重试仅撤销对应的读取错误。浏览器行为回归入口为 `tests/ui/workbench-polish.spec.js`，并随现有16显示组合检查。

- `npm ci`；`npm run dev`：浏览器外观预览。
- `npm run dev:electron`：构建后启动品牌原生宿主。macOS复制并临时签名独立 StorageLab.app，不修改 node_modules/Electron.app；默认1440×900，最小920×620。热开发可先启动Vite，再设置 `STORAGELAB_DEV_URL=http://127.0.0.1:5173/ node scripts/dev-electron.mjs`。
- `npm test`：隔离Node领域/原生服务测试；`npm run build`：生产renderer构建。
- `npm run test:ui`：安装的Google Chrome外观/交互fixture测试、16显示组合、系统主题、焦点和滚动。可在环境更换时修改 playwright.config.js channel，或安装对应Playwright浏览器后移除channel。测试fixture不代表原生服务。
- `STORAGELAB_TEST_CONFIG=<private-local-config.json> npm run test:native`：真实Electron生产入口隔离启动+实际safeStorage隔离SQLite roundtrip；真实本地MinIO工作流、上传文本预览/下载字节比较/签名fetch/受控删除/活跃任务取消/设置重载。未配置私有本地MinIO时只跳过provider工作流，保留生产启动测试。凭证配置格式和回环限制见protocol.md。

native测试文件/目录picker和删除确认在测试原生组合中依赖注入，renderer仍使用同一生产UI/preload/IPC/service；不能视为人工操作系统对话框验收。测试代理仅对ListBuckets注入403，对象请求实际访问本地MinIO；403不能称为MinIO原生IAM返回。测试使用独立目录与随机桶，finally清理。

当前 macOS 开发宿主验收不代表安装包、Windows/Linux、全部S3厂商或未解锁可见桌面人工验收。开发宿主与安装资源使用current维护源中的StorageLab专用标准/小尺寸图标，来源和生成流程见[品牌及发布流程](desktop-packaging.md)。


## 任务文件操作与版本窗口（2026-10-28）

任务卡片右侧状态行收纳三个图标操作：打开本地文件、打开所在目录、删除记录；不为普通完成任务增加底部操作行。图标有文字名称和悬停提示，操作中锁定同条任务。原生删除确认默认保留文件，勾选后移到系统回收站；角色区分、旧记录及续传保护见[任务文件说明](task-files.md)。

下载自动保存最终绝对路径；任务列表及刷新据此实际检查文件。文件不在原位置时显示状态并禁用打开/定位按钮，仍可仅删除记录；打开操作允许下载文件编辑后的正常使用，移到回收站仍独立核验身份。操作后刷新状态，不用“有路径关联”代替“文件存在”。

对象版本与恢复窗口最大宽1120px。顶部连接/桶上下文与完整原始Key查询分组，输入与读取按钮底部对齐，Key原样保留；宽窗口历史列表与版本详情左右排列，面板不超过1000px时改为上下排列。历史列表独立滚动并保持可视高度，类型/状态/时间/大小/版本ID列固定分工。详情采用属性对照布局，完整版本ID可选取，Metadata默认折叠；保留规则等长说明使用问号帮助。错误和结果复用消息组件，底部关闭/下载/恢复固定，不随正文滚动。
