# README 图片维护

此目录保存产品首页使用的本地图标、截图与微信二维码，独立上传仓库后仍可显示。截图可点击查看原图。

- `logo.svg` 来自本产品现用品牌副本；品牌修改后按产品图标流程同步。
- `wechat-qr.png` 复用官网“扫码加微信”的原文件；不要称为公众号二维码。更新时同时更新产品站与系列仓库。
- 截图的采集日期、环境、尺寸、来源与 SHA-256 见 [manifest.json](manifest.json)。历史原生截图与浏览器演示截图分别标注，不表示当前安装包或所有云账号已验收。
- 更新截图时使用隔离数据、回环服务与生成的演示文件；不显示真实凭证、签名链接、个人路径或客户信息。完整窗口保留原比例，不修改界面文本或拼造运行结果。
- 替换图片后同步首页说明及清单，检查大图可读性、相对路径与文件体积；二维码保留清晰原件。
