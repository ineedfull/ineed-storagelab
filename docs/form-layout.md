# 录入表单布局与核验

StorageLab 使用 `src/styles/tokens.css` 的语义尺寸：单行输入、数字与下拉普通外高 34px，大字外高 40px。多行文本、复选框与设置开关保留各自尺寸。

连接表单通过 `.connection-field` 组织标签、控件及下方说明；普通标签与带帮助按钮的标签行均至少 32px，避免签名区域/默认桶等同行字段被帮助按钮挤出高低差。列使用 `minmax(0, 1fr)`，字段使用 `min-width: 0`；说明在控件下方换行。现有表单的行为与提供商校验继续由对应组件和领域模块维护。

弹窗共用 `AppDialog`：标题和底栏固定，正文独立滚动。末尾字段必须能实际滚入可见区并获得焦点，不能只验证弹窗外壳没有溢出。标签、Metadata 编辑行的移除按钮与单行输入等高对齐；版本查询按钮与多行 Key 控件底部对齐。
