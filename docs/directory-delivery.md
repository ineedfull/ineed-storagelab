# 目录交付与内容核验

在对象浏览中选择连接、桶和前缀，点击「目录交付」。支持上传本地目录、下载当前远端前缀、逐项 SHA-256 核验及导出 JSON 交付清单。仅 Electron 原生环境可执行，浏览器预览不访问文件系统。

## 使用流程

1. 选择上传或下载，以及目标已存在时「跳过」或「允许覆盖」。通过系统窗口选择本地目录。
2. 预览相对路径、原始 Key、大小和冲突结果。上传保留子目录，所选根目录名不加入 Key；下载移除当前前缀后映射到所选目录。
3. 检查后开始传输。关闭窗口或切换页面不停止任务；重新打开可查看批次、取消和导出清单。
4. 在文件详情查看 SHA-256、核验来源及两侧摘要。传输已经提交但核验失败时，批次仍失败，清单会同时保留实际提交结果和核验错误。

上传保守沿用单文件的条件写入策略：MinIO/通用 S3 等未确认可靠不覆盖能力的入口，必须明确选择允许覆盖并重新预览；仅 HEAD 检查不能保证并发时不覆盖。下载的跳过策略也不等于核验本地已有文件。跳过项没有内容一致结论。

只读连接只能下载。预览和运行期间连接配置被锁定；清除预览、关闭窗口、预览到期或批次结束后释放。预览授权10分钟有效、仅可启动一次；原生授权路径不向页面返回。

## 核验依据与成本

- 上传：流式读取源文件计算完整 SHA-256，上传后 HEAD，再按版本或 ETag 条件完整 GET 远端内容并比对。会产生额外一次完整远端读取和相应流量/请求费用，需要 GetObject 权限。
- 下载：对 GET 响应流计算 SHA-256，落盘后完整读取本地文件比对。远端版本和长度在执行时检查；原始远端 Key 与本地相对路径分别传递。
- ETag 不作为 MD5 或 SHA-256。这里证明本次读取与传输内容的一致性；摘要不提供数字签名、来源认证或远端永久不变保证。

文件发生变化、长度不符、版本不符、摘要不符、网络错误均不能标记核验通过。取消会中止后续核验，保留已经提交的文件与状态证据，未开始项标为取消；已经提交的文件不会因取消而自动删除。

## 范围与限制

每次最多1000个文件、10000遍历项、32层；单文件不超过64GiB。分页最多100页，重复/缺失游标或枚举超限会拒绝整次预览。符号链接、特殊文件、非法可移植文件名、大小写/Unicode别名和文件/目录冲突保留为阻止项，不静默改名。空文件可传输，空目录和零字节目录标记不创建对象。

最多两个活动批次，每批最多八项进入已有队列窗口，实际并发仍由设置中的1–4控制。独立批次表保留完整结果，不受普通任务200条淘汰影响；历史最多20个终态批次，活动批次始终可见。批次项目不提供普通任务重试，需重新选择目录预览；进程重启将未完成批次标记中断，不自动恢复目录授权。已有单文件上传续传继续独立使用。

首版不比较目录、不自动删除远端或本地文件、不跨云迁移，也不承诺目录整体原子提交。路径检查沿用现有本地安全边界；应选择自己控制的目录，避免其他本地进程并发修改目录树。

## 清单与维护

JSON 包含 schemaVersion、产品版本、批次时间/方向/桶/前缀、文件相对路径及原始 Key、各项状态、核验来源和摘要。清单不含凭证、本地绝对路径或签名 URL。批次本地保存失败时会明确警告，会话内仍保留真实结果供立即导出；退出后未落盘结果无法恢复。公开 URL 按批次创建时的 publicBaseUrl 生成，连接后来修改不会改写旧清单；`urlStatus=generated-not-access-verified` 表示尚未核验匿名访问权限。私有对象仍需单独分享。

SQLite schema3 仅增加 directory_batches，兼容 schema1/2 的连接、凭证、任务与本地文件关联。实现分为 directory-plan（有界枚举与映射）、integrity（流式完整摘要）、directory-service（原生授权/队列/持久化）和共享窗口 DirectoryDelivery。

本轮隔离验证包括真实 Electron 主入口、IPC、AWS S3 SDK、本地 HTTP 存储夹具和磁盘往返；不访问146发布桶。真实云账号、真实 MinIO 服务、Windows/Linux 原生安装和更长压力需各自验收，不能从该夹具推定。

持续验收与故障恢复记录见[目录交付验收](directory-delivery-acceptance.md)，显式长跑入口为 `npm run test:directory:soak -- --seconds=1200 --idle=180`。批次历史超出保留范围后，当前选择会清空并提示重新选择；重启修正未完成条目，同时保留已完成文件的实际核验证据。
