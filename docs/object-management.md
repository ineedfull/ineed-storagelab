# 对象复制、重命名与元数据

2026-10-28。选择对象并展开详情，可打开“复制对象”“重命名对象”或“编辑元数据”。窗口固定连接/桶/原始Key；读取属性失败不能提交。提交由原生再次确认，并在确认前后核对源快照。单次仅支持已知大小≤5GiB且有ETag的对象。

## 使用及结果

复制/重命名填写同桶目标完整Key，字符原样保留，不能与源相同；默认不覆盖。当前只有AWS身份且Endpoint为保守白名单内的官方HTTPS S3地址时，启用官方文档定义的目标条件复制及条件删除，AWS账号尚未实际验收。AWS身份下手动填写的非官方地址也视为未知。未知提供商以及本轮实测MinIO均要求明确勾选允许覆盖，未授权时拒绝写入。

重命名是复制再删除，不是事务。复制后核验目标及源快照，只有条件删除能力已确认的接入才尝试删除当前源（不永久删除指定版本）。若源变更或无法安全删除，报告“复制完成，源保留”；删除响应不明确则单独报告“源删除结果不明确”，请核对两处后再处理，勿重复整个重命名。ETag不隔离同正文并发变更。版本控制开启时，删除当前源按服务规则产生删除标记，历史仍保留。

本轮实际MinIO RELEASE.2025-09-07忽略CopyObject目标IfNoneMatch以及DeleteObject IfMatch：已通过占用目标仍被覆盖、错误ETag仍删除的隔离请求确认。因此该接入始终保留重命名源，不能宣称已自动完成完整重命名；界面会明确给出结果。

元数据编辑支持Content-Type、Cache-Control和整组自定义Metadata。自定义键使用HTTP token ASCII且不区分大小写，值可见ASCII，总大小≤2KiB；不得重复。保存使用同Key条件源复制REPLACE元数据，保留未编辑的Content-Disposition、Content-Encoding、Content-Language、Expires和WebsiteRedirectLocation，正文不变。支持标签的接入保留标签；已明确不支持标签的接入不发送TaggingDirective COPY。源ACL、加密和保留规则不照搬，新对象按桶默认规则；务必核对是否符合业务需要。AWS另附目标IfMatch，其他服务没有原子目标保护。

所有Copy/删除客户端只尝试一次。超时/网络失败可能发生在写入之后，应刷新核实。只读连接在UI及原生均阻止写入。操作完成后窗口锁定提交，关闭时刷新当前相同连接/桶并将焦点移到刷新按钮；取消原生确认保留草稿。未改变连接数据、应用身份或凭证策略。
