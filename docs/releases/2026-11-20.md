# StorageLab 1.0.1 测试版

发布日期：2026-11-20。

## 本版调整

- 整理连接与对象操作交互、任务管理和多厂商适配模块，提高维护可读性。
- 导出采用安全写入流程，保留凭证保护、传输授权与本地文件操作的边界。
- 补充 MinIO 上传下载[快速上手](../quick-start.md)，纠正原生厂商接入、签名区域及目录交付的旧说明。

## 安装与验证范围

从[官网下载页](https://storagelab.ineedfull.com/downloads/)选择系统与 CPU 架构，按页面列出的文件和构建标识下载。当前只有 Electron 版，自带 Chromium，内存和磁盘占用相对较大。构建命令与矩阵见[打包指南](../desktop-packaging.md)。

本版按测试安装包分发，未配置 macOS Developer ID / 公证或 Windows Authenticode 正式签名。Windows 包使用 Linux/Wine 交叉构建；生成文件不代表 Windows/Linux/macOS Intel 已全部通过实机安装升级验收。本批实际构建、摘要与运行检查以发布交接记录为准。

厂商预设与隔离协议测试不等于所有真实云账号认证通过。安装前退出应用并备份整个用户数据目录，保留应用身份；操作系统安全后端不可用时应明确选择会话凭证模式，不能明文降级。本批不发布自动更新 feed。
