# 任务记录与本地文件

任务卡片右侧提供“打开本地文件”“打开所在目录”“删除任务记录”。操作只接受任务 ID，原生端根据私有文件关联定位文件，界面不能传入任意路径。

## 删除确认

- 默认只删除任务记录，保留本地文件与远端对象。
- 根据保存的最终路径确认本地普通文件仍存在时，原生确认框可勾选同时将文件移到系统回收站，默认不勾选；明确区分“上传源文件”与“下载文件”，并显示本地目标位置。
- 取消确认保留记录和文件。文件移动失败保留记录；如果文件已移到回收站但数据库删除失败，明确提示两步的实际结果，可再次仅删除记录。
- 传输中、排队中、正在取消或尚未收尾的任务不能删除。有续传记录或正在处理恢复的任务，必须先显式放弃续传和处理分片，不会因删除记录自动丢失续传记录或对云端发起清理。
- 将文件移到回收站前，必须等待本应用所有传输停止；移除过程中暂时阻止新任务，保护尚未生成最终文件关联的下载目标。仅删除记录不需要停止其他任务。

## 文件关联与兼容

SQLite schema2 为原生文件关联新增 `job_files` 表，schema1 原连接、设置和任务原样升级。上传的文件选择器授权、下载成功安装最终目标后记录本地引用；普通重试与重新授权的续传分别使用新任务 ID。成功下载后的关联保存失败只提示警告，不把已经完成的下载误报为失败。

关联包括规范化的最终绝对路径、文件角色及设备号/inode/大小/修改时间/创建时间。下载流完成并成功安装最终文件时自动保存关联，普通下载与指定版本下载使用同一入口。任务列表根据保存的位置实际检查普通文件是否存在，不把“有数据库关联”等同于“文件仍存在”；重启后继续使用这个位置检查。

打开和定位允许文件被编辑后继续使用，但拒绝符号链接或不可访问位置；移到回收站仍核验最初文件身份，避免误删后来替换或修改的内容。文件已不在原位置时显示“本地文件已不存在”，打开按钮停用，删除确认仅移除记录且不提供回收文件勾选。校验与系统路径 API 交接之间无法提供跨进程原子锁，不声称能阻止外部程序在交接瞬间替换文件。

历史任务没有保存本地位置，不猜测原目录，只支持删除记录。界面和任务导出不包含私有路径。删除记录、自动淘汰旧历史时级联清除文件关联；文件引用仅用于查看和显式移除，不替代续传重新选择文件及完整 SHA-256 核验。

## 验证边界

Node 隔离测试覆盖迁移、重启、历史淘汰、取消、替换/丢失/符号链接、文件操作失败、部分成功、重试及续传保护。浏览器测试覆盖按钮、错误反馈和16显示组合。macOS Electron 原生测试使用生成的临时文件，S3响应和目录选择使用隔离fixture，下载流、最终保存与路径入库调用真实service；展示与文件操作使用真实生产 main/preload/IPC/service 与系统 `shell.openPath` / `showItemInFolder` / `trashItem`；确认选择由测试自动提供。Windows/Linux 系统交互及安装包尚未验收。
