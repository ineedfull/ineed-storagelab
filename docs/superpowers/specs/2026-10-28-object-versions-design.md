# 对象版本与恢复

用户授权继续既定管理与恢复方向，并明确无需逐项确认。本子项在现有Vue/Electron S3工作台新增版本窗口，不改变SQLite schema1、应用ID、凭证策略或依赖。

## 交互与范围

- 对象工具栏“版本与恢复”允许输入完整原始Key，详情入口默认选中Key；可以查找当前已删除的Key。打开窗口不自动扫描。
- 显式读取ListObjectVersions，Prefix为完整Key，MaxKeys200；只显示严格相等Key的数据版本和删除标记。双标记分页原样保留，下一页替换，避免无限增长。不把相邻前缀对象当目标版本。
- 版本列表固定列宽，显示数据/删除标记、最新标记、本地毫秒时间、大小、版本ID。数据版本可查看HEAD属性和可读的Object Lock保留/Legal Hold头；缺失表示未知，不能推断无保护。
- 指定版本下载复用原生目录授权和流式队列；job保留versionId，重试不能丢失版本。相同Key各版本落到相同本地相对路径，默认不覆盖；界面独立勾选允许覆盖。null版本可变，下载前明确提示。
- 恢复使用CopyObject将固定历史数据版本复制为当前Key，源Key逐段编码、VersionId按query编码。只允许非空非null版本ID、HEAD确认源版本与ETag及大小、桶versioning为enabled、大小不超过5GiB。显式原生二次确认目标/版本/覆盖语义，确认后重新核验桶状态与源，CopySourceIfMatch保护源；目标不提供原子CAS，后续并发写可能成为最新，不宣称永远当前。
- Copy metadata/tags，不复制旧ACL、SSE配置或Object Lock保留规则；新对象遵循桶默认策略。失败可能写入后丢响应，重新读取核实，不自动重试恢复。只读原生阻断；删除标记无下载/恢复按钮；不永久删除版本、不改版本控制/保留策略。
- R2已知无版本API，界面及原生拒绝；其余提供商按真实服务/权限响应，不因预设存在宣称云端验证。

## 分层

`electron/s3/versions.js`持有列表/属性/恢复协议；service持有上下文、锁及原生确认。IPC白名单校验版本/双标记/原始Key，renderer没有任意路径或长期凭证。Vue版本composable独立请求代次，关闭/Key变更后忽略旧响应；窗口固定连接/桶上下文。
