# StorageLab 用户指南

StorageLab是对象存储工具箱，在MinIO和通用S3之外提供常用云存储接入，其中OSS/OBS/COS/TOS使用官方SDK原生数据面。提供商选项表示配置和能力规则，不代表该云账号已实测兼容。仅Electron原生宿主可进行真实操作，浏览器仅预览外观。

## 连接与浏览

云提供商在新建/编辑中选择，填写服务地域（R2另填Account ID）后点“应用提供商配置”生成Endpoint、签名区域和寻址方式；下拉切换本身不会改地址。OSS/OBS/COS/TOS使用原生SDK及原生Endpoint；旧版S3身份仅兼容已有连接，新建时不再提供。签名区域与服务地域可能不同，例如Spaces用us-east-1签名。COS桶名含APPID、七牛使用S3空间名。R2/B2及旧版OSS S3接入不开放对象标签；原生OSS不沿用旧S3标签限制。详细示例、能力限制和凭证映射见[云存储接入](cloud-providers.md)。上传是否支持原子不覆盖按提供商能力判断；不支持时须核对目标并明确允许覆盖，不能承诺默认强不覆盖。所有预设仍可手动覆盖，内网/代理/特殊辖区请按提供商规则配置。

选择“新建连接”，填写名称/分组、提供商、完整HTTP(S) Endpoint、区域/签名区域、寻址方式、可选默认桶、只读和公开地址。签名区域输入初始留空，应按真实服务填写；S3类留空时校验层使用其回退规则，不能据此推定实际地域。Endpoint不允许用户名密码、query或hash；不要把凭证放到URL。填写Access Key / Secret Key，长期凭证通常不填Session Token，临时凭证按服务要求填写。安全后端可用时可加密保存，也可明确选择会话模式；不可用时仅允许会话模式。编辑留空保留原凭证，更换必须完整填写。任务使用中禁止修改/删除连接。删除连接不删除远端对象。

检查连接优先检查已知桶；无桶时列桶。账号不能ListBuckets时仍可手输合法已知桶后浏览，不必获得全账号权限。连接检查通过仅说明当次检查权限，不能保证写入权限。region、path style或服务端时钟错误可导致签名失败；先核对配置和系统时间，不关闭TLS验证。

左侧选择桶，按前缀进入/返回上级；刷新和下一页用于分页。单页最多200，筛选与排序仅作用当前页，不是全桶搜索。Key按原始字符处理，反斜杠和dot segments并非本地目录。长Key可查看/复制完整值。禁止对生产桶用本工具测试删除、覆盖等破坏性操作。

选择对象查看属性/metadata/ETag。ETag不保证MD5。预览先HEAD：文本/JSON最多2MiB，PNG/JPEG/GIF/WebP最多8MiB，并限制实际读取；不执行HTML/SVG或metadata。超限、未知类型或无权限可正常下载后由合适工具查看。对象切换会丢弃旧预览响应。

## 对象标签

选择对象，展开详情，在“对象标签”按需读取；读取失败有独立错误，不等于无标签。添加或移除行后点“保存标签”，由原生确认显示连接、桶、完整 Key 和版本。保存替换整组标签，移除全部后保存会清空；“撤销编辑”恢复已读取内容，“重新读取（丢弃草稿）”取最新远端状态。切换对象/连接/路径会丢弃草稿。只读连接只能查看。

最多10项；Key唯一且1–128、Value 0–256个UTF-16单元，字母、数字、空格及 `_ . : / = + @ -`，`aws:`前缀保留。键和值保留大小写和首尾空格。服务可能有额外限制；本轮隔离MinIO版本拒绝中文标签（对象Key仍支持中文），会显示`INVALID_TAGS`，请按实际提供商规则修改。

标签与Metadata独立，不修改文件正文或Content-Type。需要HEAD/GetObject、GetObjectTagging，保存/清空另需PutObjectTagging/DeleteObjectTagging权限；特定版本还需要相应版本操作权限。读取先HEAD解析当前版本，再对该版本读标签，保存固定同一VersionId；`null`版本与未开启版本控制的对象仍可被替换，不能当成不可变对象。无版本时编辑当前对象。保存前会重新读标签比较，差异返回`CONFLICT`；S3标签API不支持原子条件写，检查后的竞争窗口无法消除。网络失败后先重新读取核实远端状态，再决定是否重试。

详见[行为与验证](object-tags.md)。

## 对象版本与恢复

打开桶后点“版本与恢复”，或从详情进入此Key的版本窗口；输入完整原始Key并显式读取，可查找当前已删除对象的历史。每页最多200，区分数据版本和删除标记，只展示严格相等Key；分页标记原样传递，某页没有匹配项不等于没有全部历史。

选择数据版本查看属性及可读保留信息。未返回保留头表示未知，不代表无保护。“下载所选版本”由原生选择目录并进入任务中心，记录/重试保留VersionId，默认不覆盖本地同名文件；`null`版本可变，获取其当时内容。

“恢复为当前对象”会原生再次确认，将固定历史数据复制成当前Key的新版本，保留原历史/删除标记。仅允许已确认开启版本控制的桶、不可变VersionId及≤5GiB；只读、未知/暂停桶和null版本不能恢复。复制Metadata和标签，不照搬旧ACL/加密/保留规则，须核对桶默认规则。目标没有原子条件保护，并发写入仍可能成为最新；失败后先重新读取核实，不盲目重复恢复。R2接入不支持版本API；其余按实际服务/权限响应。

操作与权限/兼容性限制详见[对象版本与恢复](object-versions.md)。

## 复制、受控重命名与元数据

对象详情提供复制、重命名、编辑元数据入口；保留原始Key字符，单次复制上限5GiB。保存经过原生确认和源快照复核。默认不覆盖只对明确支持条件写入的官方AWS端点开放；MinIO和未知服务须明确允许覆盖。MinIO重命名完成复制后保留源，界面会提示部分完成，请核实后自行决定是否删除。元数据编辑重写对象属性并可能生成新版本，保留未编辑的标准属性及支持的标签，使用桶默认权限/加密/保留规则。网络结果不明时先刷新，不盲目重复。详见[对象管理](object-management.md)。

## 传输与任务

上传使用原生文件选择器选多个文件（不递归目录），目标为当前桶/前缀；默认拒绝覆盖，可显式选覆盖。无原子不覆盖能力时明确报告限制，不悄悄覆盖。扩展名推断Content-Type只帮助预览，不验证文件内容。单文件上限64GiB。

选中对象下载到原生目录选择器指定的位置；路径不安全、大小写/同名冲突、Windows非法名称或符号链接风险可被拒绝，原始远端Key不会被改写。默认拒绝覆盖。临时文件完成后排他/原子提交，取消或失败清理半成品；成功表示流与磁盘提交完成，不表示额外内容摘要校验。

任务中心显示真实字节/速率/状态与错误；切换页面仍运行。最多100排队，最近保留200；并发默认2可设置1–4。取消queued立即取消，running进入cancelling后按实际完成结果收尾。普通任务重试仅适用于本会话仍有文件授权的failed/cancelled；重启后interrupted需要重新选择文件。上传前可显式勾选“启用上传断点续传”，仅支持8MiB–64GiB普通文件。取消或退出保留已确认分片，任务中心点“重新选择文件并续传”重新授权；完整SHA-256/大小和远端分片核验一致后才继续。下载不支持断点恢复。退出会有界等待清理。远端完成但历史保存失败时显示持久化警告，不重写为远端失败；请先核查远端后决定是否重试。导出任务使用原生保存位置，不包含凭证或签名链接。

## 分享与删除

签名GET默认900秒，支持60–604800秒；临时凭证可能更早失效。生成链接不等于已验证可访问，持有链接者可在有效期访问，请按密钥同等谨慎分享。URL只保留当前弹窗，关闭即丢弃。公开URL必须单独配置base URL并按完整Key编码；无法安全表示dot segments时拒绝，不能替换签名URL主机。

删除最多200个选中对象，原生确认会显示桶/数量/Key与版本语义。只读在主进程强制。已开启版本控制的“删除当前对象”可能生成删除标记，不等于永久清除；版本权限不足显示unknown。HTTP200仍可能含逐项Errors，检查部分失败列表后再处理。取消确认不发删除；不提供历史版本永久删除、版本控制开关或桶策略编辑。

## 设置、数据与恢复

设置支持系统/浅/深、普通/大字、侧栏折叠、并发和超时；草稿预览，取消或保存失败恢复原设置。关于展示真实版本、Electron运行时和独立数据目录。时间为本地YYYY-MM-DD HH:mm:ss.SSS。

网络断开或403：先检查当次错误与桶级权限，修正配置/网络后刷新；普通上传失败会清理本任务multipart，续传上传保留记录供恢复或明确放弃；下载失败清理临时文件。磁盘/SQLite失败应保留目录并先备份，不能用清空数据当常规修复。会话凭证重启后重填；操作系统安全后端故障时不导出/降级明文，可用显式会话模式临时工作。数据迁移边界见[架构](architecture.md)。

续传记录最多100个；不再需要时使用“放弃续传并清理分片”，原生确认后清理。连接配置已变化或删除时只允许明确放弃本机记录，旧服务的未完成分片需人工核实。创建或完成响应不明时禁止盲目重试，详见[续传限制](resumable-upload.md)。

当前未实现桶创建/策略/版本控制开关/历史永久清理、跨云同步、下载断点恢复、自动更新或Tauri。目录批量上传/前缀下载使用下方“目录交付”入口，区别于普通多文件上传。提供商、目标平台、人工系统对话框及升级验收范围见[验证记录](verification.md)。

连接成功保存（包括修改端点或凭证）或移除后，原生撤销该连接终态任务的重试授权与私有上下文，公开任务历史保留。需重新选择文件/目录，以当前连接重新创建任务；保存/移除失败不会撤销仍有效的授权。活动任务继续受连接锁保护。


重复启动会唤回既有窗口。OSS/OBS/COS/TOS 原生下载按无数据空闲时间超时，持续传输的大文件可以超过设置秒数完成。

## 目录交付

对象浏览选择桶/前缀后点击「目录交付」，选择方向和覆盖策略，经原生目录选择与映射预览后开始。每项保留传输结果、SHA-256核验依据；批次可取消和导出JSON。上传核验会额外完整读取远端内容，跳过文件没有核验结论；目录批次重启后需重新选择。详见[目录交付与内容核验](directory-delivery.md)。
